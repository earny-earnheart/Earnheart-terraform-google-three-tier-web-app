# Governance

The platform's technical controls are described in [Platform](https://app.gitbook.com/o/2smdwazqwLM4RyBf4nnz/s/PQ2GmOf68qXiLqjUBtjb/). This space covers the rules those controls exist to enforce.

Two ideas run through all of it. **Every action is traceable** — if an audit record cannot be confirmed, the operation is unverified regardless of what the response said. And **consequential actions stop for a human** — the authorizing principal is TCW, and no hard-stop executes without his explicit confirmation.
